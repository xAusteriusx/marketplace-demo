# Marketplace PWA de demostración

Maqueta estática con datos ficticios. No ingresar documentos ni datos personales reales.

## GitHub Pages

Subir estos archivos a la raíz del repositorio. En Settings → Pages elegir Deploy from a branch, rama main, carpeta / (root). Activar HTTPS.

Abrir la URL publicada en Chrome para Android y elegir Instalar aplicación o Agregar a pantalla de inicio. Abrir desde el ícono para usar el modo independiente. En iPhone usar Safari → Compartir → Agregar a pantalla de inicio.

La maqueta puede abrirse sin conexión después de una primera carga completa. Facebook y WhatsApp requieren conectividad. Las operaciones y preferencias se guardan solo en el dispositivo; no hay backend.

Nombre e ícono provisionales. Para futuras versiones con archivos nuevos, actualizar CACHE en sw.js. Cerrar las ventanas de la app permite activar un service worker nuevo.
